# Exam Seat Allocation System

## About the Project
The Exam Seat Allocation System is a Python-based application designed to manage students and allocate examination seats efficiently.

   Features
- Student Management
- Room Management
- Login System
- Dashboard
- Automatic Seat Allocation
- Examination Report Generation
- Student Search
- Database Management

   Technologies Used
- Python
- SQLite Database
- Python Functions
- Basic Data Structures
